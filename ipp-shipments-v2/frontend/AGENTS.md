# Frontend — Agent Notes

Read [../AGENTS.md](../AGENTS.md) first. This file adds frontend-specific rules.

## Layout

```
frontend/
├── src/
│   ├── components/
│   │   └── ui/          # shadcn primitives (generated by pnpm dlx shadcn@latest add)
│   ├── lib/
│   │   ├── env.ts       # validates VITE_* env vars at boot — import from here, nowhere else
│   │   ├── http.ts      # thin fetch wrapper (base URL, JSON, timeout, typed errors)
│   │   ├── api.ts       # typed API methods built on http.ts
│   │   └── supabase.ts  # supabase-js client (anon key only)
│   ├── pages/
│   │   ├── Login.tsx
│   │   ├── Dashboard.tsx
│   │   ├── ShipmentGate.tsx     # Domestic or Export selector
│   │   ├── DomesticBuilder.tsx  # sticker-only flow
│   │   ├── ExportBuilder.tsx    # full export flow
│   │   └── Admin.tsx            # customer/shipper management
│   ├── App.tsx          # React Router routes + auth guard
│   ├── main.tsx
│   └── index.css        # Tailwind directives + theme tokens
├── index.html
├── vite.config.ts
├── tsconfig.json
├── .npmrc
└── package.json
```

## Package manager

**pnpm only.** Never use `npm install` or `yarn add`. Lockfile is `pnpm-lock.yaml`.
If `package-lock.json` or `yarn.lock` appear, delete them — they are bugs.

Add shadcn components with:
```bash
pnpm dlx shadcn@latest add <name>
```

## Running

```bash
pnpm install
pnpm dev
```

## Drag-and-drop builder (key UI)

Uses `@dnd-kit/core`. Layout:

- **Left panel**: scrollable list of entity cards — Customers and Shipper.
- **Right panel**: labeled drop zones.
  - Domestic: `Shipper` zone only.
  - Export: `Consignee`, `Shipper`, `Notify Party 1`, `Notify Party 2` zones.
- Dropping a customer on **Consignee** auto-fills `port_of_discharge` and `payment_terms`
  from that customer's defaults.
- Entity cards are `useDraggable`; drop zones are `useDroppable`.

## Auth

- Supabase email auth. No social sign-in.
- `supabase.ts` exposes the client. Never read `VITE_SUPABASE_*` vars outside `lib/env.ts`.
- `App.tsx` wraps protected routes in an auth guard that checks `supabase.auth.getSession()`.
- The API client in `lib/api.ts` attaches the Supabase JWT automatically.
- Never thread auth tokens through component props.

## HTTP

- All backend calls go through `api.get / api.post / api.patch / api.delete` from `lib/api.ts`.
- Never use axios, ky, or any HTTP library. Native `fetch` only.
- Backend URL comes from `env.ts` → `VITE_API_BASE_URL`.

## TypeScript

- Strict mode. No `any`. Prefer `unknown` and narrow.
- One component per file.
- Tailwind classes inline — no CSS modules, no styled-components.

## No tests

Do not write `*.test.ts` / `*.test.tsx`. Verify manually in the browser.
Type-check with `pnpm tsc --noEmit`.

## Anti-patterns

- Reading `import.meta.env.*` outside `lib/env.ts`.
- Importing fetch/HTTP libraries.
- `any` annotations.
- Hand-rolling a component that shadcn already ships.
- Next.js, SSR, or any server-rendered approach.
